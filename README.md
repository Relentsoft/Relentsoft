## 🇬🇧 English

Relentsoft is a digital development agency specializing in building robust web applications, automating complex workflows, and integrating cutting-edge AI solutions. We engineer scalable infrastructure for local businesses, real estate management, and educational platforms.

### 💻 Our Tech Stack
* **Backend & API:** Python, Flask, PostgreSQL, REST APIs
* **Frontend:** Mobile-first HTML, CSS, JavaScript
* **AI & Automation:** Google Gemini API, Document Parsing algorithms
* **Infrastructure:** Git, deployment pipelines, secure database management

### 🚀 Featured Projects
* **GetStudyFlow:** A comprehensive student productivity platform featuring custom 'squad duels' functionality, powered by a robust Flask and PostgreSQL backend.
* **Real Estate Genius:** An AI-driven application designed to automate the parsing and management of dense property management and Landlord/Tenant Board documents.
* **Local Business Architecture:** Engineering lightning-fast, high-converting, mobile-optimized bilingual static sites for local service businesses.

## 🇫🇷 Français

Relentsoft est une agence de développement numérique spécialisée dans la création d'applications web robustes, l'automatisation de flux de travail complexes et l'intégration de solutions d'IA de pointe. Nous concevons des infrastructures évolutives pour les entreprises locales, la gestion immobilière et les plateformes éducatives.

### 💻 Notre Pile Technologique
* **Backend & API :** Python, Flask, PostgreSQL, API REST
* **Frontend :** HTML, CSS, JavaScript (Orienté mobile)
* **IA & Automatisation :** API Google Gemini, Algorithmes d'analyse de documents
* **Infrastructure :** Git, pipelines de déploiement, gestion sécurisée de bases de données

### 🚀 Projets Vedettes
* **GetStudyFlow :** Une plateforme complète de productivité pour étudiants intégrant une fonctionnalité personnalisée de « squad duels », propulsée par un backend robuste Flask et PostgreSQL.
* **Real Estate Genius :** Une application propulsée par l'IA conçue pour automatiser l'analyse et la gestion de documents denses de gestion immobilière et de la Commission de la location immobilière (CLI).
* **Architecture pour Entreprises Locales :** Conception de sites statiques bilingues, ultra-rapides et optimisés pour les appareils mobiles destinés aux entreprises de services locales.
